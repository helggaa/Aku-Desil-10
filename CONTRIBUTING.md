# Panduan Kontribusi (Contributing Guidelines)

Terima kasih atas minatmu untuk berkontribusi pada **Aku Desil 10 ☝️🤓**!

Proyek ini dibangun dengan komitmen teguh terhadap:
1. **Transparansi Metodologi Statistik**: Formula harus selalu berakar pada data publik resmi (Susenas BPS / data terbuka kredibel).
2. **Privasi Mutlak (*Privacy by Absence*)**: Tidak ada penambahan pelacak, telemetri, database, atau cookies.
3. **Aksesibilitas & Kualitas Kode**: Menggunakan Vanilla JavaScript, HTML5 semantik, dan CSS modern tanpa dependensi berat.

---

## 🛠️ Cara Berkontribusi

1. **Fork Repositori**: Buat fork repositori ini ke akun GitHub kamu.
2. **Buat Branch Fitur / Perbaikan**:
   ```bash
   git checkout -b feature/nama-fitur-kamu
   ```
3. **Lakukan Perubahan**: Pastikan kode mematuhi standar keamanan, tanpa dependensi eksternal/CDN pelacak, dan tidak merusak alur kalkulasi Susenas.
4. **Uji di Berbagai Peramban**: Pastikan tampilan responsif dan kalkulasi akurat di Chrome, Firefox, Safari, dan Edge.
5. **Kirim Pull Request (PR)**: Jelaskan secara rinci perubahan yang kamu buat dan alasan di baliknya.

---

## 📌 Melaporkan Isu atau Diskusi Formula
Jika kamu menemukan anomali perhitungan atau ingin mendiskusikan kalibrasi $\mu$ dan $\sigma$ terbaru BPS, silakan buka [GitHub Issues](https://github.com/helga-id/aku-desil-10/issues).
